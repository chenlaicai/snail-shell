# F2026060901 [web] 全新 UI 重建 — Linear 风格 Issue Tracker

## 背景

旧 UI 存在根本性问题：60+ 未定义 CSS 类名、CSS 层叠层冲突（全局 reset 覆盖 Tailwind 工具类）、数据获取模式不一致（useEffect + api() 绕过 TanStack Query）、大量死代码。用户决定完全移除旧 UI，基于效果图从零搭建。

效果图提供三张 Linear 风格设计稿：Issue Board（Kanban）、Issue List、Issue Conversation。

### CSS 层叠层策略

globals.css 仅包含 `@import "tailwindcss"` + `@theme inline`，不添加任何全局 reset。Tailwind 的 Preflight 处理浏览器默认样式。自定义颜色通过 `@theme inline` 的 CSS 变量定义，Tailwind 自动生成工具类。

## Issue 生命周期

```
创建 Issue → 首个 Stage (in_progress)
  ↓
与 Agent 对话（消息流式接收）
  ↓
Agent 请求工具权限 → ToolApprovalCard (Approve/Deny)
  ↓
Stage 完成 → advance / confirm-stage-suggestion
  ↓
下一个 Stage 或 complete / archive
```
