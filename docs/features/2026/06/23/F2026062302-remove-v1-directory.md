# F2026062302 [core] 移除 v1 遗留目录

<!-- [design-time] 以下章节在需求收敛与设计阶段（代码前）完成并锁定 -->

## 背景

仓库根目录下存在 `v1/` 目录，包含旧版架构的全部代码（agent、persistence、web、interaction-entry 等）。当前系统已在 `src/` 下完成重构，v1 代码无任何活跃引用，但仍在仓库中占据约 39,000 行代码和 333 个文件。

## 目标

移除 `v1/` 目录，减少仓库体积和维护负担。

## 非目标

- 不涉及 `src/` 下任何功能变更
- 不涉及数据库 schema 或 API 变更
- 不涉及构建流程调整

## 核心业务行为

| # | 场景 | 预期行为 | 测试覆盖 |
|---|------|----------|----------|
| B1 | 移除 v1 后执行 `npm run build` | 构建正常通过，无编译错误 | `npm run build` 通过 |
| B2 | 移除 v1 后执行 `npm run lint` | lint 无新增报错 | `npm run lint` 通过 |
| B3 | 搜索 `src/` 中对 `v1/` 的引用 | 无任何 import 或路径引用 | grep 验证无匹配 |

## 设计

### 方案

直接 `git rm -r v1/` 移除整个目录。经 grep 验证，`src/` 下无任何对 `v1/` 的 import、require 或路径引用，移除不会影响现有功能。

### 设计取舍

纯清理操作，无设计取舍。

## 生效路径

通过 git 移除 `v1/` 目录下全部 333 个文件。

## 设计约束摘要

- **边界**：仅删除 `v1/` 目录，不修改任何其他文件
- **语义不变量**：`src/` 下所有功能不受影响
