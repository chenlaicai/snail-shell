# F2026052905 [lobby] IM 大厅 — 系统级 IM 接入

<!-- [design-time] 以下章节在需求收敛与设计阶段（代码前）完成并锁定 -->

## 背景

当前飞书集成是对话级静态绑定：一个飞书群 chat_id 通过 `config/feishu.json` 的 `bindings` 映射到一个 Snail Shell conversation_id。用户无法从飞书端浏览项目、切换 feature 或导航系统。本次改造将 IM 集成从"对话桥"升级为"系统级大厅"。

## 目标

### P1 — 大厅导航与房间对话

1. IM 群聊连接到整个 Snail Shell 系统（而非单个 conversation）
2. 用户通过斜杠命令导航：`/projects` → `/features <id>` → `/enter <id>` 进入具体 conversation（房间）
3. 房间内可直接与 Agent 对话，Agent 回复推送到 IM
4. `/back`、`/lobby` 退出房间回到大厅导航
5. 整个群共享一个导航状态（非 per-user）
6. Web 端新增"IM 大厅"一级模块，展示所有 IM 会话状态

## 非目标

1. 不支持自然语言命令解析（无 LLM 成本）
2. 不支持 IM 卡片交互（纯文本，预留扩展接口）
3. 不支持 per-user 导航状态
4. 不支持从 IM 端创建项目/feature
5. 不支持图片、文件、语音消息

## 设计

### P1 详设

#### 架构分层

```
IM Platform Layer (Feishu, 未来 WeChat/Slack)
  ↓
LobbyAwareChannel (大厅感知通道，替代 FeishuConversationChannel)
  ↓
LobbyRouter (路由：大厅命令 vs 房间转发)
  ↓
LobbyCommandExecutor (命令执行) + ConversationGateway (房间消息)
```

#### 数据模型

- `lobby_session`: 每个 IM 群一个会话，记录导航状态（lobby/project_list/feature_list/in_conversation）
- `lobby_message`: 审计日志，记录入站命令和出站响应
- UNIQUE(channel_type, channel_chat_id, channel_tenant_key): 一个群一个会话

#### 命令协议

| 命令 | 作用 |
|------|------|
| `/projects` | 列出所有项目 |
| `/features <project_id>` | 列出项目下的 feature |
| `/enter <feature_id>` | 进入 feature 当前 stage 的 conversation |
| `/back` | 返回上一级 |
| `/lobby` | 直接回到大厅根 |
| `/status` | 查看当前位置 |
| `/help` | 显示帮助 |

#### 路由逻辑

1. `navigation_level === 'in_conversation'` 时：
   - `/back`、`/lobby` → 执行命令退出房间
   - `/status`、`/help` → 执行命令
   - 其他所有消息（含其他斜杠命令）→ 转发到 conversation
2. 大厅导航模式时：
   - 斜杠命令 → 执行命令
   - 普通文本 → 提示使用命令

#### 响应渲染抽象

`LobbyResponseRenderer` 接口定义所有响应场景的渲染方法。首版实现 `PlainTextLobbyRenderer`（纯文本），预留 `card` 字段供未来 `FeishuCardRenderer` 使用。

#### IM 通道抽象

`LobbyAwareChannel` 实现 `IMChannelAdapter` 接口，包装 `FeishuTransport`，消息先经 `LobbyRouter` 判断去向。进入房间时动态 `gateway.subscribe()`，退出时取消订阅。

#### 配置

`config/feishu.json` 使用 `allowed_chats` 白名单配置允许接入大厅的飞书群。移除旧 `lobby_enabled`、`bindings` 字段。

#### Web UI

新增"IM 大厅"一级模块，展示所有 lobby_session、当前导航状态、大厅消息审计。提供重置到大厅、删除会话、查看消息等操作。

## 生效路径

- 代码：`src/lobby/`（核心逻辑）、`src/interaction-entry/im-channel/`（通道层）、`src/interaction-entry/api/lobby-routes.ts`（API）
- 配置：`config/feishu.json`（`allowed_chats`）
- Web UI：`src/web/lobby-controller.js`、`src/web/lobby-view.js`、`src/web/styles/components/lobby.css`
