# 产物类型决策矩阵

治理裁决去向通过 `tags` 和 `metadata` 记录。

## 决策表

| 场景特征 | 裁决去向 | tag | 后续动作 |
|----------|----------|-----|----------|
| 一次性结论，无长期复用价值 | 仅记录结论 | （无额外 tag） | 关闭治理对话 |
| 需要修改系统提示词 | 系统提示词变更 | `system-prompt` | 与用户协商方案，由用户推进 PR |
| 需要新增或修改 skill | Skill 变更 | `skill` | 与用户协商方案，由用户推进 PR |
| 需要更新用户手册 | 文档变更 | `user-manual` | 记录更新内容和位置 |
| 需要代码或检查器变更 | 代码变更 | `code` | 与用户协商方案，由用户推进 PR |
| 适合沉淀为长期知识 | 知识库条目 | `knowledge` | 使用 knowledge-library skill create 模式写入 |

## 决策原则

1. **优先评估是否真的需要长期产物**：不是所有治理对话都需要产出 PR 或知识库条目
2. **一个演进项对应一个主要去向**：如果涉及多个去向，拆分为多个演进项分别治理
3. **裁决结果必须与用户确认**：不要单方面决定后直接执行
