# Ask User Protocol

## Purpose

当你无法安全替用户做决定，或者某个决定会影响后续工作边界、输入、输出时，你必须向用户提问。

## When To Use

1. 需求存在歧义。
2. 多个方案都合理，但需要用户选择。
3. 某个决定会影响后续阶段输入或输出。
4. 当前信息不足以安全继续推进。

## Rules

1. 需要用户明确决策时，不得擅自替用户做决定。
2. 问题必须指向真实待决策项。
3. 要说明为什么现在必须问。
4. 选项应覆盖真正可行的决策分支。
5. 正式问题卡片必须通过 `message-out question` 输出。
