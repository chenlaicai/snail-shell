# 提示词治理 — 参考约束

## 归属判断

[STD] 调整提示词前对照 `.meta/README.md` 判断归属：
1. 对所有 Snail 底层 AI 都成立且不依赖工作区上下文的规则 → Base 层（id 前缀 B-）
2. 依赖工作区/阶段/角色上下文的规则 → Scenario 层（id 前缀 S-）
3. 详细操作步骤、模板、脚本 → skill
4. 按需查阅的参考约束 → `.meta/prompts/reference/`
5. Base 层不超过 3 条，Scenario 层单次会话不超过 3 条

## 跨层污染

[STD] 禁止将 Scenario 层规则写入 Base 层模块，禁止将工作区特定规则写入全局 prompt。一条规则只能有一个主归属。
