# 实现 — 参考约束

## DB Schema 与 Migration

[STD] DB schema、migration 等数据库约束：
- 不得在 migration 中执行不可逆破坏性操作（DROP TABLE、DROP COLUMN）—— 先在后续 migration 中标记废弃，由用户决定清理时机
- 新增 NOT NULL 列必须提供默认值
- migration 必须可回滚（提供 down 脚本或说明回滚步骤）

详细规则见 developer-handbook skill。

## 不兼容变更

[STD] 不兼容变更只在 issue 文档中说明，不构建兼容性桥接或过渡逻辑。代码仓在任何时刻都是最终完美状态，不保留废弃分支或临时包装。
